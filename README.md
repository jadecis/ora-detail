# ORA Detail

Веб-приложение студии детейлинга: каталог автотоваров, услуги, корзина, заказы и запись на обслуживание. Пет-проект, объединяющий интерфейс на Vue и REST API на Express.

**Стек:** Vue 3, Vue Router 4, Vite 7, SCSS, Node.js, Express 4.

## Возможности

- Каталог товаров и услуг.
- Корзина и оформление заказов.
- Запись на услуги и история обращений.
- Регистрация, вход и профиль.
- API чтения и изменения каталогов, заказов и записей.

## Запуск

Нужны Node.js, совместимый с Vite 7, и npm:

```bash
npm ci
```

В двух терминалах из корня репозитория:

```bash
npm run server
```

```bash
npm run dev
```

Откройте адрес Vite из терминала. API по умолчанию использует порт 3001, проверка состояния доступна по `/api/health`. Сервер читает переменную `PORT`.

Сборка: `npm run build`. Предпросмотр: `npm run preview`. Статическая сборка интерфейса не включает Express API.

## Структура

- `src/pages/` — главная, товары, услуги, корзина и профиль.
- `src/components/` — общие компоненты.
- `src/router/` — маршрутизация.
- `server/index.js` — REST API.
- `data/` — JSON-каталоги и файловое хранение данных.
- `src/assets/` — изображения и иконки.

## Статус

Демонстрационный проект. Перед публичным размещением API необходимы отдельная проверка авторизации и прав доступа, а также подготовка обезличенных данных. JSON-хранилище рассчитано на прототип; production-эксплуатация не подтверждена.
